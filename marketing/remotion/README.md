# audx promo video (Remotion)

A 20-second promo for audx, built with [Remotion](https://www.remotion.dev).
The soundtrack is a UK garage 2-step loop at 132 BPM that audx sequenced, and the
step grid, playhead and waveform scope in the video follow that audio frame by frame.

## Generate the beat, then render

The composition reads `src/beat-data.json` and plays `public/audx-beat.wav`. Both
come from one script (run it from the repo root; it needs ffmpeg on your PATH):

```bash
uv run python marketing/build-beat.py   # writes public/audx-beat.wav and src/beat-data.json
```

Then, in this directory:

```bash
npm install

npm run studio        # live preview in the browser
npm run render        # out/audx-promo.mp4  (1920×1080, 30fps, with audio)
npm run render-gif    # out/audx-promo.gif  (no audio)
npm run still         # out/poster.png      (a frame from the sequencer scene)
```

`npm run render` downloads a headless browser and an ffmpeg binary on first use,
so it needs network access and a few hundred MB of disk.

## How the beat is made

`marketing/build-beat.py` synthesises its own one-shots (kick, clap, rim, hats,
sub bass notes and electric-piano chords), sequences every part with audx's
`Song`/`render_song` engine at 22% swing, mixes the stems with a kick sidechain and
a reverb send, then sets loudness with ffmpeg. The first two bars are keys and hats
only, and the full groove comes in on bar three.

It also writes the sidecar the video reads:

- `tracks[]`: label, 16-step grid and the video frame of every hit, swing included
- `envelope[]`: per-frame RMS of the master
- `waveform[]`: downsampled peaks for the scope

```
src/
  index.ts        # registerRoot
  Root.tsx        # <Composition>: 600 frames @ 30fps, 1920×1080
  AudxPromo.tsx   # Frame, Hero, Sequencer (grid and scope), CTA
  theme.ts        # palette and font
  beat-data.json  # generated by build-beat.py (committed)
public/
  audx-beat.wav   # generated by build-beat.py (gitignored, regenerate it)
```

Change copy or timing in `AudxPromo.tsx`, colours in `theme.ts`, or the beat in
`marketing/build-beat.py`, then re-render. The finished video and poster are kept in
`marketing/promo/`.

The terminal-typing GIF in the top-level README (`docs/assets/audx-demo.gif`) is
separate, generated offline by `scripts/make-demo-gif.py` (Pillow only).
